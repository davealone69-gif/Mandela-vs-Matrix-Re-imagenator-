# Mandela Matrix OS

Jetpack Compose Android app with Free AI, Swarm Builder, Training Centre, and the full Mandela feature set.

**Repo:** https://github.com/davealone69-gif/MandelaMatrixOS

## CI

`.github/workflows/android-build.yml` builds debug + release APKs on push to main.

## Free AI

Optional Groq / OpenRouter API key in the Free AI tab enables live replies (`LlmClient`).

## Sources

Core Gradle, CI, MainActivity, navigation, Models, LlmClient, and several screens are on main. Upload any remaining screen files from the full project zip if Actions is missing sources.
