# Mandela ve Matrix Re-imagenator

Production-ready Android starter with multi-module architecture, Compose, modern Gradle Kotlin DSL, CI/CD, and Play Store publishing.

## Requirements
- Android Studio Ladybug or newer
- JDK 17
- Android SDK 34

## Quick Start
```bash
git clone https://github.com/davealone69-gif/Mandela-Matrix.git
cd Mandela-Matrix
./gradlew :app:assembleDebug
```

## Modules
- `:app` – main application
- `:libs` – shared library

## CI Secrets required
- `KEYSTORE_BASE64`
- `KEYSTORE_PASSWORD`
- `KEY_ALIAS`
- `KEY_PASSWORD`
- `PLAY_STORE_JSON`
